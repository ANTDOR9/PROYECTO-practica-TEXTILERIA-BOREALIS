# Textilería Borealis 🧵


Proyecto frontend realizado como práctica, basado en un catálogo visual de artesanías y textiles peruanos.  
El objetivo de este repositorio es **aprender y practicar React, Vite, CSS y el flujo de trabajo con Git/GitHub**.

> ⚠️ Este proyecto no incluye backend ni base de datos.  
> Todo el contenido es estático y de uso educativo.

---

## 🛠️ Tecnologías usadas

- React
- Vite
- JavaScript
- JSX
- CSS
- Node.js
- npm

---

## ▶️ Ejecución del proyecto

Para ejecutar el proyecto en tu computadora, sigue estos pasos:

### 1. Clonar el repositorio
```bash
git clone https://github.com/TU-USUARIO/Textileria-Borealis.git
```
###2. Entrar a la carpeta del proyecto
```
cd Textileria-Borealis
```
###3. Instalar dependencias
```
npm install
```
###4. Ejecutar en modo desarrollo
```
npm run dev
```

Luego abre el navegador en la URL que aparece en la terminal (normalmente):

http://localhost:5173

###📁 Estructura básica

```
src/

 ├─ main.jsx

```
